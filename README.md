# CostoChef Pro

Proyecto React + Vite para el archivo `RestauranteCostos.jsx`.

## Ejecutar localmente

1. Instala Node.js 18+.
2. En esta carpeta, ejecuta:
   ```bash
   npm install
   npm run dev -- --host
   ```
3. Abre la URL que muestra Vite en el terminal.

## Despliegue en Vercel

1. Sube esta carpeta a un repositorio GitHub/GitLab/Bitbucket.
2. Conéctalo en Vercel como nuevo proyecto.
3. Vercel detectará el proyecto y usará:
   - Build command: `npm run build`
   - Output directory: `dist`

También hay `vercel.json` incluido para que la configuración de despliegue sea estática.
